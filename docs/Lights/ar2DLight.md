# ar2DLight

2D light fixture symbol for floor plans. Circle or rectangle, built into ceiling or wall, with three representation levels: Simple, Detailed, or By MVO (driven by the [arMVO](../MVO/arMVO.md) settings part).

**Source:** [`Library_Src/Lights/ar2DLight/`](../../Library_Src/Lights/ar2DLight/)

## Parameters

| Parameter | Meaning |
|-----------|---------|
| `shape` | Krog (circle) / Pravokotnik (rectangle); B hidden for circle |
| `builtIn` | Strop (ceiling) / Stena (wall) |
| `representation2D` | Simple / Detailed / By MVO |
| `A`, `B` | Symbol size |
