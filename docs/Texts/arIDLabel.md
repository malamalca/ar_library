# arIDLabel

Element ID label. Text object that displays the ID of the element it is placed on (doors, windows, walls, ...), with selectable text orientation and font.

**Source:** [`Library_Src/Texts/arIDLabel/`](../../Library_Src/Texts/arIDLabel/)

## Parameters

| Parameter | Meaning |
|-----------|---------|
| `labelOrientation` | Follow Label Rotation / Always Horizontal |
| font parameters | Text font |
