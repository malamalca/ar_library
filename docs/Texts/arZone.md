# arZone

Room / zone label. Placed inside a room; shows the full room number (`<masterID> <ROOM_NUMBER>`), optionally with area, elevation and description lines taken from the parent room element, plus an optional underline under the title.

**Source:** [`Library_Src/Texts/arZone/`](../../Library_Src/Texts/arZone/)

## Parameters

| Parameter | Meaning |
|-----------|---------|
| `roomNumberFull` | `<masterID> <ROOM_NUMBER>` (locked, computed) |
| `drawLineUnderTitle` | Underline under the title |
| `showArea`, `showElevation`, `showDescription` | Show extra room data lines |
