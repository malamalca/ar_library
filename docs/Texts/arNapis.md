# arNapis

Text note. Free text object with support for GDL variables, e.g. `<projectAltitude>` in the text is replaced by the project's absolute altitude value.

**Source:** [`Library_Src/Texts/arNapis/`](../../Library_Src/Texts/arNapis/)

## Parameters

| Parameter | Meaning |
|-----------|---------|
| `fontFace` | Text font (custom) |
| text | Note content, may contain variables like `<projectAltitude>` |
