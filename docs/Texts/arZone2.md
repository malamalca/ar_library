# arZone2

Room / zone label, variant 2. Same data as [arZone](arZone.md) (room number, area, elevation, description from the parent room element) with a different layout.

**Source:** [`Library_Src/Texts/arZone2/`](../../Library_Src/Texts/arZone2/)

## Parameters

| Parameter | Meaning |
|-----------|---------|
| `roomNumberFull` | `<masterID> <ROOM_NUMBER>` (locked, computed) |
| `drawLineUnderTitle` | Underline under the title |
| `showArea`, `showElevation`, `showDescription` | Show extra room data lines |
