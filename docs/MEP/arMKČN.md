# arMKČN

Manhole (jašek) variant built on [arJašek](arJašek.md) (`CALL "arJašek" PARAMETERS ALL`) with an added standard type **TIMS 6PE** (sets A = 2.2 m).

**Source:** [`Library_Src/MEP/arMKČN/`](../../Library_Src/MEP/arMKČN/)

## Parameters

| Parameter | Meaning |
|-----------|---------|
| `kind` | Samo pokrov (cover only) / Okrogla po meri / Pravokotna po meri / TIMS 6PE |
| `A`, `B` | Shaft dimensions (per kind) |
| `latchKind` | Okrogel / Kvadraten pokrov |
