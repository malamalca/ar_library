# arVgradnaOmara

Built-in cabinet with slatted front. Built-in utility cabinet (e.g. for meters) with a louvered / slatted door: slat count, spacing and tilt angle are adjustable; 2D symbol plus 3D box.

**Source:** [`Library_Src/MEP/arVgradnaOmara/`](../../Library_Src/MEP/arVgradnaOmara/)

## Parameters

| Parameter | Meaning |
|-----------|---------|
| `A`, `B` | Cabinet width / height |
| slat parameters (count, spacing, tilt) | Slatted front layout |
| `bShowText` | Always / Never (name text) |
