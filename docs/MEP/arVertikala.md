# arVertikala

Vertical pipe (riser). Vertical MEP run built from up to 50 segments (e.g. stacked in stories); each segment is a straight length of the same pipe.

**Source:** [`Library_Src/MEP/arVertikala/`](../../Library_Src/MEP/arVertikala/)

## Parameters

| Parameter | Meaning |
|-----------|---------|
| `nSegments` | Number of segments (1–50) |
| `segments[i]` | Segment lengths |
| `segment_edit_index`, `ui_segment_index` | UI proxy for segment editing |
