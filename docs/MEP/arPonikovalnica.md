# arPonikovalnica

Infiltration pit (soakaway / ponikovalnica). Variant of [arJašek](arJašek.md) (`CALL "arJašek" PARAMETERS ALL`) for stormwater infiltration: cover-only, custom round or custom rectangular body.

**Source:** [`Library_Src/MEP/arPonikovalnica/`](../../Library_Src/MEP/arPonikovalnica/)

## Parameters

| Parameter | Meaning |
|-----------|---------|
| `kind` | Brez (none) / Okrogla po meri / Pravokotna po meri |
| `A`, `B` | Shaft dimensions (per kind) |
| `latchKind` | Okrogel / Kvadraten pokrov |
