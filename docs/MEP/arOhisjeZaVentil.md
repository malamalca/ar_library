# arOhisjeZaVentil

Vent housing (ohišje za ventil). Ceiling- or wall-built-in housing for a ventilation grille (Ø 150 mm), as intake (zajem) or exhaust (izpust), with three representation levels: Simple, Detailed, or By MVO (driven by the [arMVO](../MVO/arMVO.md) settings part).

**Source:** [`Library_Src/MEP/arOhisjeZaVentil/`](../../Library_Src/MEP/arOhisjeZaVentil/)

## Parameters

| Parameter | Meaning |
|-----------|---------|
| `cKind` | Zajem (intake) / Izpust (exhaust) |
| `cBuiltin` | Strop (ceiling) / Stena (wall) |
| `representation2D` | Simple / Detailed / By MVO |
