# arFasadnaRešetka

![arFasadnaRešetka](../../images/arFasadnaRešetka.png)

Facade ventilation box (intake+exhaust). Wall-mounted outdoor ventilation unit with curved casing, pipe connections and a slatted front; 2D symbol plus 3D body.
