# arVodomerniJašek

Water meter manhole (jašek za vodomere). Variant of [arJašek](arJašek.md) (`CALL "arJašek" PARAMETERS ALL`): cover only, custom round, standard round (with wall width), or **Zagožen** (keyed / sealed) type.

**Source:** [`Library_Src/MEP/arVodomerniJašek/`](../../Library_Src/MEP/arVodomerniJašek/)

## Parameters

| Parameter | Meaning |
|-----------|---------|
| `kind` | Samo pokrov / Okrogla po meri / Okrogla tipska / Zagožen |
| `A`, `B` | Shaft dimensions (per kind) |
| `wallWidth` | Wall width for the standard round type (locked) |
| `latchKind` | Okrogel pokrov |
