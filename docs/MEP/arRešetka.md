# arRešetka

Grille / grating symbol. Simple rectangular grille made of vertical slats with configurable spacing, used as a 2D MEP symbol (drainage, ventilation).

**Source:** [`Library_Src/MEP/arRešetka/`](../../Library_Src/MEP/arRešetka/)

## Parameters

| Parameter | Meaning |
|-----------|---------|
| `A`, `B` | Grille width / height |
| slat spacing / count parameters | Slat layout |
