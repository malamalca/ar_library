# arPrismVolume

Not fully implemented yet.

Computes the volume of a prism formed by an [ar3DPolygon](../3D/ar3DPolygon.md) base and a cut plane defined by position, rotation and inclination; reports base area, base circumference and body volume.

**Source:** [`Library_Src/2D/arPrismVolume/`](../../Library_Src/2D/arPrismVolume/) · [Wiki](https://github.com/malamalca/ar_library/wiki/2D-Objects)

## Parameters

| Parameter | Meaning |
|-----------|---------|
| `base_area` | Base polygon area (locked, computed) |
| `base_circumreference` | Base polygon perimeter (locked, computed) |
| `body_volume` | Prism volume (locked, computed) |
