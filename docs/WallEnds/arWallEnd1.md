# arWallEnd1

![arWallEnd1](../../images/arWallEnd1.tiff)

Wall end cap. Accessory for the ends of (composite) walls, straight or curved; caps the wall thickness with a computed cut width / angle and optional cap surface override. Uses `FM_types` (standard ArchiCAD type table).

**Source:** [`Library_Src/WallEnds/arWallEnd1/`](../../Library_Src/WallEnds/arWallEnd1/)

## Parameters (main)

| Parameter | Meaning |
|-----------|---------|
| curved / straight kind | Cap geometry follows the wall end radius `r0` |
| `cutWidthAngle`, `thickCapAngle` | Computed cap angles (auto-synced with arc lengths) |
| `bOverrideStructureSurface`, `matCap` | Cap surface override |
| `bOverrideCutFillPens`, cut fill pens | Cut fill pen overrides |
