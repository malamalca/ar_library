# arZaključekOgraje1

Fence termination post (zaključek ograde). End post for a fence run: profile diameter, base length and cap; 2D symbol plus 3D post.

**Source:** [`Library_Src/Ograje/arZaključekOgraje1/`](../../Library_Src/Ograje/arZaključekOgraje1/)

| Parameter | Meaning |
|-----------|---------|
| `profile_diameter` | Post profile diameter |
| `base_length` | Post length above the base |
